# Word Counter

A clean, minimal word counter web app with instant word and letter totals as you type.

## Features

- Live word count
- Live letter count
- Clean modern UI with a designer-inspired layout
- Clear button resets text and counts
- Built with Vite and vanilla JavaScript

## Project structure

```text
word-counter/
├── index.html
├── package.json
├── public/
└── src/
    ├── main.js
    └── style.css
```

## Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open the local development URL shown in the terminal to view the app.

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Notes

- The app uses a simple textarea input to count words and letters in real time.
- The design emphasizes simplicity, readability, and smooth spacing for a premium feel.
